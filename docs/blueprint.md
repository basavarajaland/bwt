# **App Name**: BWT Creations

## Core Features:

- Website Mirror: Mirrors the layout, content, and overall design from the target BTWIMF website, using web scraping and appropriate formatting.
- Content Updates: Fetches latest content and design changes from the original site daily or weekly, and incorporate them.
- Responsive Design: Ensures that mirrored content and layout adjust seamlessly across different devices (desktops, tablets, mobiles).
- Enhanced UI Elements: Uses AI as a tool to automatically identifies elements on BTWIMF, and recommends visual enhancements while keeping their essence; user has the final decision to publish. Includes suggestions for typography, layout adjustments for clarity, or iconography.
- SEO Optimization: Uses generative AI to suggest and implement standard SEO practices such as updating meta tags.

## Style Guidelines:

- Primary color: Deep teal (#116466) for a blend of trustworthiness and sophistication, subtly hinting at creative industry associations.
- Background color: Very light grayish teal (#E4EDED) to create a calming, uncluttered backdrop that highlights content.
- Accent color: Muted coral (#D1495B) as a striking contrast for calls to action and important information, enhancing user engagement.
- Headline font: 'Belleza' sans-serif, for a fashion-forward style; body font: 'Alegreya', for readability and personality.
- Use sharp, minimalist icons that reflect design elements, providing easy visual cues.
- Modern grid-based layout with an emphasis on white space to create balance and clarity.
- Use subtle transitions and animations to guide users without causing distraction.
